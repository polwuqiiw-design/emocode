# Публикация ЭмоКод через GitHub Pages

## 1. Создать репозиторий
1. Войдите на https://github.com и нажмите **New repository**.
2. Название: `emocode` (Public), затем **Create repository**.

## 2. Загрузить сайт
1. В созданном репозитории нажмите **Add file → Upload files** (или ссылку uploading an existing file).
2. Распакуйте ZIP и перетащите **содержимое** папки: `index.html`, `app.js`, `style.css`, `.nojekyll` (скрытый файл можно пропустить), `README.md`.
3. Нажмите **Commit changes**.
4. Проверьте, что `index.html` лежит в корне репозитория, а не внутри дополнительной папки.

## 3. Включить GitHub Pages
1. **Settings → Pages**.
2. **Build and deployment → Source: Deploy from a branch**.
3. **Branch: main**, **Folder: /(root)** → **Save**.
4. Дождитесь завершения публикации (обычно несколько минут). Откройте адрес, показанный в Settings → Pages.

Адрес обычно выглядит так: `https://USERNAME.github.io/emocode/`, где USERNAME — ваш логин GitHub.

## 4. Проверить с телефона
Откройте адрес в мобильном браузере, пройдите несколько вопросов, проверьте игру, диаграмму и сохранение портрета в PDF.

## 5. QR-код
Когда сайт заработает, скопируйте **точный публичный URL** и пришлите его в чат — подготовим QR-код для презентации. Не кодируйте локальный путь `file:///...` или ссылку на ZIP.

## Конфиденциальность и научный статус
Сайт статический, без базы данных и отправки ответов на сервер. Показатели доступны на устройстве участника; общего сбора результатов нет. Это образовательный проект: ERQ представлен в учебном переводе, 48 дополнительных вопросов — авторские, не валидированные. Не используйте отчёт как официальное заключение психолога.
