# ЭмоКод

Интерактивный образовательный проект: 58 вопросов, 10 шкал самооценки, мини-игра «Распознавание эмоций», визуализация результатов и печать психологического портрета в PDF.

Сайт статический, сервер не нужен. Откройте `index.html` локально или разместите файлы на GitHub Pages.

Инструкция по публикации: **ПУБЛИКАЦИЯ.md**.

Разработчицы: Пацан Мария и Полторацкая Анастасия, студентки 2-го курса ПОО РГПУ им. А. И. Герцена.

Научные ограничения: ERQ используется в учебном переводе, 48 авторских утверждений не прошли психометрическую проверку; результаты не являются официальным психологическим заключением.

## Версия 8: темперамент

Добавлен отдельный учебный блок из 24 авторских вопросов (12 на экстравертированность, 12 на эмоциональную реактивность), после задания на распознавание эмоций. Результат отображается на странице итогов и в печатном психологическом портрете. Это **не EPI**, не валидированная адаптация и не профессиональная диагностика темперамента. Условная четырёхтипная интерпретация используется только для иллюстрации модели Айзенка; при пограничных значениях показывается смешанный профиль.
